# ✈️ 우리 가족 해외여행 기록장

가족 4명(전정순·허인선·허형준·김민정)의 해외여행을 구글 시트에 기록하고, 아래 두 가지 횟수를 **따로** 세어 줍니다.

- **출국 횟수**: 한국에서 나간 횟수 (한 번 나가서 여러 나라를 가도 1회)
- **나라 방문 횟수**: 다녀온 나라마다 1회씩 (한 번 나가서 일본·태국을 가면 2회)
- **도시**: 나라마다 다녀온 도시를 고를 수 있고, **가본 나라 N개 · 가본 도시 N개**로 따로 셉니다.
- 덤으로 **가본 나라 수**(중복 제외), 총 여행일수, 연도별 출국 횟수도 보여 줍니다.

나라 이름만 입력하면 **국기(🇯🇵 이모지 + 국기 이미지)** 가 자동으로 들어갑니다.
나라 칸에 `오사카`, `다낭`처럼 도시 이름을 쓰면 **나라(일본) + 도시(오사카)** 로 알아서 나눠 줍니다.
자주 가는 도시 약 450개가 자동완성으로 나오고, 목록에 없는 도시도 자유롭게 쓸 수 있습니다.

## 구조

```
[GitHub Pages]  index.html  ──fetch(POST JSON)──▶  [Google Apps Script]  gas/*.gs  ──▶  [Google 시트]
   화면 (통계·목록·입력)                              저장/조회 API                     여행기록·통계·나라별·국가목록
```

| 경로 | 어디에 두나 | 내용 |
|---|---|---|
| `index.html` | **GitHub Pages** | 화면. 맨 아래 `API_URL`에 Apps Script 웹앱 주소가 들어 있음 |
| `gas/Code.gs` | Apps Script | 시트 생성, 국기 자동 입력, 통계 계산, API(`doPost`) |
| `gas/Countries.gs` | Apps Script | 나라 이름·별칭 ↔ 국가코드 목록 (148개), 나라별 도시 목록 |
| `gas/appsscript.json` | Apps Script | 프로젝트 설정 (서울 시간대) |

Apps Script에는 HTML 파일이 없습니다. 웹앱 주소는 JSON만 돌려주는 API입니다.

## 설치

### 1. Apps Script (시트 저장 담당)
1. 구글 시트에서 **확장 프로그램 → Apps Script**를 엽니다.
2. `gas/` 안의 파일을 붙여 넣습니다.
   - `Code.gs`, `Countries.gs` → **＋ → 스크립트**
   - `appsscript.json` → 톱니바퀴(프로젝트 설정)에서 **"appsscript.json" 매니페스트 파일 표시**를 켠 다음 내용을 바꿉니다.
   - 예전에 넣은 `Index.html`이 있다면 삭제합니다.
3. **가족 비밀번호 설정**: `Code.gs`의 `setFamilyKey` 함수에서 `'여기에-가족-비밀번호'`를 원하는 비밀번호로 바꾸고 `setFamilyKey`를 실행합니다.
   비밀번호는 스크립트 속성에 저장되므로, 실행한 뒤에는 코드를 원래대로 되돌려도 됩니다. **GitHub에는 비밀번호를 올리지 마세요.**
4. 함수 목록에서 **`setup`** 을 실행합니다. 권한을 허용하면 아래 작업이 한 번에 끝납니다.
   - `여행기록` / `통계` / `나라별` / `국가목록` 탭 생성
   - 시트를 직접 편집할 때 국기와 통계를 다시 계산하는 트리거 설치
5. **배포 → 배포 관리 → 수정(연필)** 에서 아래처럼 설정하고 **버전: 새 버전 → 배포**를 누릅니다.
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자** (GitHub 화면에서 로그인 없이 호출해야 하므로 필요합니다. 대신 가족 비밀번호가 있어야 데이터를 보고 쓸 수 있습니다.)
   - 웹앱 주소가 바뀌면 `index.html`의 `API_URL`도 바꿔 주세요.

### 2. GitHub Pages (화면 담당)
1. 저장소 **Settings → Pages**에서 Source를 **Deploy from a branch**로 하고, `index.html`이 있는 브랜치와 `/ (root)`를 고릅니다.
2. 잠시 뒤 `https://wooriwoosin.github.io/fam/` 에서 화면이 열립니다.
3. 처음 열면 가족 비밀번호를 묻습니다. 한 번 입력하면 그 기기(브라우저)에 기억됩니다.

## 사용법

### 📄 출입국증명서로 한 번에 불러오기
1. 정부24에서 **출입국에 관한 사실증명**을 PDF로 받습니다. 증명서를 찍은 사진이나 스크린샷도 됩니다.
2. 화면의 **📄 증명서** 탭에서 누구의 증명서인지 고르고 파일을 선택합니다.
3. 출국일·입국일 목록이 나오면 증명서와 비교해서 확인합니다.
   - 빨간 줄(⚠️)은 글자 인식이 애매한 줄입니다. 날짜를 직접 고치거나 ✕로 지우세요.
   - `있음`은 이미 저장된 출국일이라 다시 저장되지 않습니다.
4. **저장하기**를 누르면 여행 목록으로 넘어갑니다. 노란 줄을 눌러 다녀온 나라를 채우면 끝입니다.

**개인정보**: 증명서 파일은 브라우저 안에서만 읽습니다(pdf.js + Tesseract.js OCR). 파일이 서버로 전송되지 않고,
주민등록번호·여권번호·이름도 저장되지 않습니다. 시트에는 **출국일과 입국일만** 저장됩니다.
정부24 PDF는 스캔 이미지라서 처음 읽을 때 글자 인식 데이터(약 10MB)를 받느라 시간이 조금 걸립니다.

### 화면에서 (휴대폰 추천)
- **통계**: 사람별 출국 횟수, 나라 방문 횟수, 가본 나라와 국기, 나라별·연도별 표를 봅니다.
- **여행 목록**: 노란색 줄은 나라가 아직 비어 있는 여행입니다. 누르면 나라를 채울 수 있습니다.
- **＋ 여행 추가**: 같이 간 사람을 **모두** 고르면 사람마다 한 줄씩 기록됩니다.
  나라를 입력하고 Enter를 누르면 그 나라 칸이 생기고, 칸 안의 **＋ 도시 추가**에 도시를 하나씩 넣으면 됩니다.

### 시트에서 직접
- `여행기록` 탭에 여행자, 출국일, 입국일을 쓰고 `방문국가` 칸에 `일본, 태국`처럼 쉼표로 구분해 입력합니다.
  `방문도시` 칸에는 `오사카, 교토, 방콕`처럼 씁니다. 목록에 없는 도시는 `아리마온천(일본)`처럼 괄호 안에 나라를 적어 주세요.
  (나라가 하나뿐인 여행이면 괄호 없이 써도 됩니다.) 국기, 기간(`2박3일`), 나라 수, 도시 수, 통계는 자동으로 채워집니다.
- 메모에 도시를 적어 두었다면 메뉴 **✈️ 여행기록 → 메모의 도시 → 방문도시로 옮기기**를 누르세요.
  목록에 있는 도시 이름만 `방문도시`로 옮기고 나머지 메모(예: `가족여행`)는 그대로 둡니다.
- 빨간 칸은 국가목록에 없는 이름입니다. `국가목록` 탭 맨 아래에 나라 이름과 2자리 코드(예: `JP`)를 추가하면 국기가 붙습니다.
  자주 쓰는 도시 이름은 `별칭` 칸에 `|`로 구분해 넣으세요.
- 메뉴 **✈️ 여행기록 → 국기·통계 새로고침**으로 언제든 전체를 다시 계산할 수 있습니다.

## API

모든 요청은 `POST`로 보내고, 본문은 JSON 문자열입니다. `Content-Type` 헤더를 지정하지 않아야 CORS 사전요청 없이 Apps Script에 전달됩니다.

| action | 추가 필드 | 설명 |
|---|---|---|
| `get` | – | 가족, 국가목록, 여행 목록, 통계 |
| `add` | `trip: { people[], dep, ret, countries: [{ name, cities[] }], memo }` | 여행 추가 (사람마다 한 줄) |
| `update` | `id`, `trip: { person, dep, ret, countries: [{ name, cities[] }], memo }` | 여행 수정 |
| `delete` | `id` | 여행 삭제 |
| `import` | `person`, `trips: [{ dep, ret }]` | 출입국증명서 날짜 한꺼번에 저장 (이미 있는 출국일은 건너뜀) |

모든 요청에 `key`(가족 비밀번호)가 필요합니다. 응답은 `{ ok: true, data }` 또는 `{ ok: false, error, auth }` 형태입니다.

## 속도
- **화면**: 저장·수정·삭제는 화면에 바로 반영되고, 시트 저장은 뒤에서 순서대로 처리됩니다. 제목 옆에 `저장 중… (2)` → `✓ 저장됨`이 표시됩니다.
  저장 중에 창을 닫으려 하면 경고가 뜹니다. 저장에 실패하면 시트의 최신 기록을 다시 불러옵니다.
- **다시 열 때**: 마지막으로 본 기록을 기기에 저장해 두었다가 바로 보여 주고, 최신 기록이 오면 바꿉니다.
- **서버**: 요청마다 여행기록을 한 번 읽고 한 번에 씁니다. 국가목록은 6시간 캐시하고, 통계 시트는 값만 씁니다(서식은 `setup` 때 한 번).
  요청 한 번에 시트 호출 수: 불러오기 17 → 3번, 추가 104 → 16번, 수정 92 → 16번, 증명서 21건 234 → 16번.
- Apps Script는 한동안 안 쓰면 첫 요청이 1~3초 정도 느립니다(구글 쪽 대기 시간). 화면은 캐시로 먼저 뜨기 때문에 기다릴 필요는 없습니다.

## 예전 버전에서 업데이트할 때
`gas/` 파일을 다시 붙여 넣고 **새 버전으로 배포**하면 됩니다. `여행기록` 탭에 `방문도시`, `도시 수` 열이 없으면
처음 API가 호출되거나 시트를 편집할 때 알아서 제자리에 끼워 넣습니다. 기존 기록은 그대로 유지됩니다.
업데이트한 뒤 편집기에서 `setup`을 한 번 실행하면 `통계`·`나라별` 탭 서식이 새 구성에 맞게 정리됩니다(기록은 지워지지 않습니다).

## 참고
- 국기 이모지는 휴대폰과 Mac에서는 국기로 보이지만, Windows에서는 `JP` 같은 글자로 보일 수 있습니다.
  그래서 `나라별` 탭과 화면은 국기 **이미지**(flagcdn.com)를 사용합니다.
- 가족 이름을 바꾸려면 `gas/Code.gs` 맨 위 `FAMILY`를 수정하세요.
