# 💗 팸레블 (FAM Travel)

우리 가족 해외여행 기록장

가족 4명(전정순·허인선·허형준·김민정)의 해외여행을 기록하고, 아래 횟수를 **따로** 세어 줍니다.

- **출국 횟수**: 한국에서 나간 횟수 (한 번 나가서 여러 나라를 가도 1회)
- **나라 방문 횟수**: 다녀온 나라마다 1회씩 (한 번 나가서 일본·태국을 가면 2회)
- **가본 나라 · 가본 도시** 수(중복 제외), 총 여행일수, 연도별 출국 횟수
- **예정 여행**(비행기 표 끊은 여행)은 D-day로 보여 주다가, 출국일이 되면 자동으로 기록과 통계에 들어갑니다.
- **같이 간 여행 묶음**마다 💰 가계부(현지화폐+원화, 결제일별), 📍 장소 기록(구글지도), 💸 정산 체크리스트가 있습니다.

나라 이름만 입력하면 **국기**가 자동으로 붙고, `오사카`·`다낭`처럼 도시 이름을 쓰면 **나라 + 도시**로 알아서 나눠 줍니다.
자주 가는 도시 약 450개가 자동완성으로 나오고, 목록에 없는 도시도 자유롭게 쓸 수 있습니다.

## 구조

```
[GitHub Pages]  index.html + config.js + countries.js  ──REST──▶  [Supabase]  trips 테이블
   화면 (통계·목록·입력·통계 계산)                             데이터 저장 (서울 리전)
```

| 경로 | 내용 |
|---|---|
| `index.html` | 화면 전체. 통계는 화면에서 오늘 날짜 기준으로 계산 |
| `config.js` | **Supabase 주소·키**, 가족 목록, 예전 구글 시트 주소(옮겨오기용) |
| `countries.js` | 나라 148개(이름·별칭·국가코드), 나라별 도시 목록 |
| `journey.js` | 여행 묶음·상세 화면, 가계부·환율, 장소·구글지도, 정산 |
| `travel.js` | ✈️ 항공편(편명으로 불러오기·경유·비행시간) · 🏨 숙소(구글 검색·몇 박·택시 카드) |
| `airports.js` | 공항 목록 (자동완성 + 시간대로 비행시간 계산) |
| `supabase/functions/flight-lookup/index.ts` | 항공편 자동 불러오기 Edge Function (API 키를 숨겨 둠) |
| `pack.js` | 🎒 준비물 체크리스트 (기본 목록 포함) |
| `trash.js` | 🗑 휴지통(지우기·되살리기), 📦 전체 백업 파일 |
| `supabase/schema.sql` | Supabase SQL Editor에서 실행하는 테이블·보안 규칙 (trips, journeys, expenses, places, settle_checks, trash, pack_items, pack_checks, change_log) |
| `.github/workflows/supabase-keepalive.yml` | 무료 프로젝트가 잠들지 않게 사흘마다 한 번 깨움 |
| `legacy.html`, `gas/` | 예전 구글 시트(Apps Script) 버전 — 옮겨오기가 끝나면 지워도 됨 |

접근은 **완전 공개**입니다(로그인·비밀번호 없음). 화면 주소를 아는 사람은 누구나 보고 고칠 수 있습니다.
나중에 가족만 쓰게 하려면 `supabase/schema.sql`의 "공개 정책"을 바꾸면 됩니다.

## 설치 (처음 한 번)

1. **Supabase 프로젝트 만들기**: https://supabase.com → New project
   - Region: **Northeast Asia (Seoul)**
   - Database Password는 본인만 보관 (어디에도 적지 마세요)
2. **테이블 만들기**: 대시보드 왼쪽 **SQL Editor** → `supabase/schema.sql` 내용을 통째로 붙여 넣고 **Run**
   (여러 번 실행해도 안전합니다)
3. **연결 정보 넣기**: **Project Settings → API (API Keys)** 에서 복사해 `config.js`에 넣습니다.
   - `supabaseUrl`: Project URL (`https://xxxx.supabase.co`)
   - `supabaseKey`: **anon** 키 또는 `sb_publishable_…` 키 (공개용)
   - ⚠️ `service_role` / `sb_secret_…` 키와 DB 비밀번호는 절대 넣지 마세요.
   - 키를 넣기 전까지는 화면이 자동으로 예전 구글 시트 버전(`legacy.html`)으로 열립니다.
4. **GitHub Pages**: 저장소 **Settings → Pages** → Deploy from a branch → 이 브랜치, `/ (root)`
   → `https://wooriwoosin.github.io/fam/`
5. **예전 기록 옮겨오기**: 화면 ⚙️ 설정 → **구글 시트 기록 옮겨오기** (한 번만. 여러 번 눌러도 중복 없음)
6. **잠들기 방지 확인**: 저장소 **Actions** 탭 → *Supabase keep-alive* → **Run workflow** 로 한 번 실행해 초록색인지 확인
   (Supabase 무료 프로젝트는 7일 동안 요청이 없으면 일시 정지됩니다. 이 작업이 사흘마다 한 번 깨워 둡니다.)

## 사용법

### 화면 (휴대폰 추천)
- **통계**: 다가오는 여행(D-day), 사람별 출국 횟수·나라 방문·가본 나라·가본 도시, 나라별·연도별 표
- **여행 목록**: 위쪽은 예정 여행, 아래쪽은 다녀온 여행. 노란 줄은 나라가 비어 있는 여행 — 누르면 채울 수 있어요.
- **＋ 추가**: 같이 간 사람을 **모두** 고르면 사람마다 한 줄씩 기록됩니다.
  나라를 입력하고 Enter → 그 나라 칸의 **＋ 도시 추가**에 도시를 하나씩. 출국일을 고르면 입국일 달력은 그 날짜부터 열립니다.
- **⚙️ 설정**: 엑셀로 내려받기(백업), 구글 시트에서 옮겨오기

### 🧳 같이 간 여행 (여행 상세)
여행 목록은 **같이 간 여행** 단위로 보여 줍니다. 누르면 **개요 · 📍 일정 · 💰 가계부 · 💸 정산 · 🎒 준비** 탭이 있는 상세 화면이 열립니다.
- **묶는 기준**: 기간이 겹치고 나라가 하나라도 같으면 같은 여행입니다. 일행마다 출국·입국일이 달라도 됩니다.
  여행 기간은 가장 빠른 출국 ~ 가장 늦은 입국. 예전 기록도 자동으로 묶입니다.
- **개요**: 일행별 날짜·나라(수정 버튼), 잘못 묶였으면 **빼기**, 근처 날짜의 다른 가족 기록 **넣기**,
  **가족 외 일행**(친구 등 — 통계에는 안 들어가고 정산에만), 여행 메모. 제목을 누르면 여행 이름을 바꿀 수 있어요.

### 💰 가계부
- **＋ 지출 추가**: 종류(항공·숙소·식비·카페·술·교통·관광·쇼핑·기타), 내용, 결제일, 통화·금액, 결제한 사람, 결제수단 메모(예: 민정 현대카드),
  함께 쓴 사람(정산에서 나눌 사람), 개인 지출(정산 제외), 연결할 장소.
- **환율**: 결제일 기준으로 자동(공개 환율 데이터, 기기에 캐시). 직접 고칠 수 있고,
  **카드 청구 원화**를 넣으면 그 금액이 우선(💳 표시). 여행 전 결제는 기본 원화, 여행 중엔 그 나라 통화가 기본입니다.
- **요약**: 총지출, 1인당, 종류별 막대, 현지화폐 합계, 결제한 사람별 금액.
- **결제일별**: ✈️ 여행 전 결제 / Day 1 · 2/4 (수) … / 🏠 여행 후 결제 — 날마다 원화·현지화폐 소계.

### 📍 일정 (장소 기록 · 구글지도)
- **＋ 장소 추가**: 구글 장소 검색(여행 나라 안에서 먼저 찾음) → 이름·주소·위치 자동. 종류(맛집·카페·술집·관광지·쇼핑·숙소·공항·기타), 간 날, 우리 가족 별점, 메모.
- **📍 지금 여기 근처**: 휴대폰 위치 주변 장소에서 골라 바로 기록.
- 여행 지도에 종류별 핀(이모지+색), 날짜별 보기, **지도** 버튼으로 구글맵 앱 열기, **＋💰**로 그 장소에서 쓴 돈 바로 기록.
- 구글 지도 키는 `config.js`의 `googleMapsKey` (Google Cloud에서 `https://wooriwoosin.github.io/*` 에서만 쓰이게, Maps JavaScript API·Places API (New)만 허용).

### ↕ 같은 날 안에서 순서 바꾸기 (가계부·장소)
- 같은 날짜 안에서는 **입력한 순서**대로 보여요. 시간은 넣지 않아도 됩니다.
- 순서가 틀렸으면 날짜 묶음 오른쪽 **↕ 순서 바꾸기** → **☰ 끌어서 옮기기** 또는 **▲ ▼** → **완료**. 가족 모두에게 같은 순서로 보여요.
- "여행 전 결제"처럼 여러 날짜가 섞인 묶음에서는 같은 날짜끼리만 옮겨져요. 다른 날로 옮기려면 그 항목을 눌러 **날짜를 바꾸면** 그 날의 맨 뒤로 갑니다.

### 💸 정산
- 사람마다 **낸 돈 / 내 몫 / 차액**, 그리고 **최소 송금 목록**(예: 허인선 → 김민정 152,000원).
- **체크리스트**: 보내면 ☑. 가족 모두에게 같이 보이고, 그 뒤에 지출이 바뀌어 금액이 달라지면 "금액이 바뀌었어요"로 알려 줍니다.

### ✈️ 항공편 (개요 맨 위)
- **＋ 추가** → 출발 날짜(현지)와 편명(예: `KE461`) → **🔍 불러오기**: 출발·도착 공항, 현지 시각, 터미널이 채워져요. 확인하고 **저장**.
  불러오기가 안 되면 공항(`ICN`, `인천`, `다낭` 다 됨)과 시간을 직접 넣어도 돼요. 비행시간은 공항 시간대로 자동 계산.
- **경유**: 구간마다 따로 넣으면, 24시간 안에 이어지는 구간은 한 여정으로 묶이고 "다낭에서 2시간 15분 환승"처럼 보여요.
- **경유지 체류 시간**: 여정마다 "총 8시간 50분 (비행 6시간 35분 · 경유지 체류 2시간 15분)"으로 보여 주고, 체류 시간에 따라 알려 줘요.
  1시간 미만은 ⚠️ 빠듯한 환승, 3~8시간은 ☕ 라운지·식사, 8시간 이상은 🏙️ 시내 구경 가능(입국·비자 확인), 밤을 넘기면 🌙,
  도착·출발 공항이 다르면(예: 나리타 → 하네다) ⚠️ 이동 시간 확인. 1~3일 머무는 스톱오버는 여정 사이에 "🏨 ○○에서 1일 5시간 머물러요"로 보여요.
- **편도·왕복**: 한국 출발 = 🛫 가는 편, 한국 도착 = 🛬 오는 편, 그 밖은 ✈️ 이동. 가는 편만 있으면 **＋ 오는 편 추가**(공항을 거꾸로 채워 줌).
- **탄 사람**: 일행 일부만 타는 구간은 이름을 골라요 (안 고르면 전체).
- 출발 이틀 전부터 **🔄 게이트·지연** 버튼으로 게이트·지연 정보를 새로 불러와요. 게이트는 보통 출발 몇 시간 전에 정해져요.
- ⚠️ 공개 앱이라 **예약번호는 적지 마세요**.

### 🏨 숙소 (개요)
- **＋ 추가** → 구글에서 숙소 검색 → 이름·주소·위치·전화 자동. 체크인·체크아웃 날짜로 몇 박인지 계산, 여러 곳 가능.
- 숙소가 비어 있는 밤을 알려 줘요 (밤새 비행하는 날은 빼고).
- **🧭 길찾기**, **🚕 택시에 보여주기**(현지어 이름·주소를 크게), **＋💰** 숙박비 기록.
- 📍 일정 탭 날짜별로 항공편(출발·도착)과 숙소 체크인·체크아웃이 **자동으로** 들어가요 (오전 일은 그날 맨 위, 오후 일·체크인은 맨 아래). 누르면 개요에서 바로 고쳐요. 숙소에 묵는 중간 날엔 "오늘 밤 숙소"가 보이고, 지도에 숙소 핀이 찍혀요.

### ✈️ 항공편 자동 불러오기 설정 (한 번만)
키를 화면에 두면 누구나 가져다 쓸 수 있어서, Supabase 안(Edge Function)에 숨겨 두고 씁니다.
1. [RapidAPI](https://rapidapi.com)에 가입 → **AeroDataBox** 검색 → **Basic(무료)** 플랜 구독 → `X-RapidAPI-Key` 복사
2. Supabase 대시보드 → **Edge Functions → Secrets** → 이름 `AERODATABOX_KEY`, 값에 1번 키 → 저장
3. **Edge Functions → Deploy a new function → Via Editor** → 이름 `flight-lookup` → `supabase/functions/flight-lookup/index.ts` 내용을 통째로 붙여 넣기 → **Deploy**
4. 그 함수의 설정(Details)에서 **Verify JWT (JWT 확인)를 끄고** 저장 — 우리 키(`sb_publishable_…`)는 JWT가 아니라서
5. SQL Editor에서 최신 `schema.sql` 실행 (캐시·하루 한도 표 포함)

- 같은 편명·날짜는 저장해 둔 결과를 다시 써요 (출발 이틀 전부터는 20분, 그 전엔 12시간마다 새로).
- 하루 15번까지만 불러와요 (무료는 한 달 약 600 "유닛"이라, 누가 마구 눌러도 한도가 금방 안 닳게). 바꾸려면 Secrets에 `FLIGHT_DAILY_LIMIT` 추가.
- 무료 플랜 한 달 한도는 RapidAPI 요금 화면에서 확인하세요. 한도를 넘으면 직접 입력하면 돼요.

### 🎒 준비물 체크리스트 (🎒 준비 탭)
- 처음에 **기본 목록**(141개: 출국 전 확인 · 소지 가방 · 기내 · 위탁 파우치별)이나 **지난 여행 목록**(체크는 비운 채)으로 시작해요.
- 목록과 체크는 **가족 공통**이에요 (누가 체크해도 모두에게 체크됨). **남은 것만**으로 안 챙긴 것만 볼 수 있어요.
- **✏️ 목록 편집**: 항목 × 로 빼기, 칸에 입력해서 추가(쉼표로 여러 개), **＋ 파우치 추가**, **＋ 묶음 추가**, 묶음·파우치 통째로 빼기, **🔄 목록 비우고 처음부터 다시 만들기**.
- **기본 목록 바꾸기**: ⚙️ 설정 → **🎒 기본 준비물 목록 고치기**에서 항목·파우치·묶음을 더하고 빼면, 앞으로 새 여행의 "기본 목록으로 시작"에 그 목록이 들어가요 (이미 만든 여행은 그대로). 여행 목록 편집 화면의 **⭐ 이 목록을 기본 준비물 목록으로 저장**으로 통째로 바꿀 수도 있고, **↩️ 처음 상태로** 되돌릴 수도 있어요.

### 🗑 삭제와 휴지통
- **여행 통째로 삭제**: 여행 상세 → 개요 맨 아래 **여행 삭제** → 여행 이름을 그대로 입력해야 지워져요. 일행 기록·가계부·일정·정산·준비물이 같이 휴지통으로 가요.
- 일행 기록 하나, 지출, 장소를 지워도 휴지통으로 가요. 여행의 마지막 일행 기록을 지우면 여행째로 가요.
- ⚙️ 설정 → **🗑 휴지통** → **되살리기** 한 번이면 그대로 돌아와요. 휴지통은 **자동으로 비우지 않아요** (**완전 삭제**를 눌러야만 없어짐).

### 🗓️ 예정 여행 (비행기 표 끊은 여행)
- 출국일을 오늘 이후로 넣으면 **예정 여행**입니다. 메모에 항공편(예: `대한항공 KE461`)을 적어 두면 편해요.
- 통계 맨 위 **다가오는 여행**에 D-day와 함께 보이고, 같은 날 같이 떠나는 가족은 한 줄로 묶입니다.
- 예정 여행은 통계에 **들어가지 않다가, 출국일이 되면 자동으로** 들어갑니다 (화면을 열 때마다 오늘 날짜로 계산).

### 백업
- ⚙️ 설정 → **📦 전체 백업 내려받기**: 모든 기록(휴지통 포함)을 JSON 파일 하나로. **📂 백업 파일로 되살리기**는 지금 없는 기록만 채우고, 있는 기록은 건드리지 않아요 (휴지통에 있는 건 빼고).
- **📥 여행 기록 / 💰 가계부 내려받기**: CSV(엑셀에서 바로 열림). 보기용이에요.
- Supabase 무료 플랜은 자동 백업이 없으니 가끔 전체 백업을 내려받아 두세요.

### 🔒 변경 기록 (최후의 안전장치)
누가 앱 밖에서 API로 지워도, DB가 **모든 수정·삭제 직전 줄**을 `change_log` 표에 자동으로 남겨요.
공개 키로는 읽지도 지우지도 못하고, Supabase 대시보드에서만 보여요. 되살리는 법 (SQL Editor):

```sql
-- 최근에 지워진 것 보기
select id, at, tbl, row_id, old_row from change_log where op = 'DELETE' order by at desc limit 50;

-- 지워진 여행 기록 하나 되살리기 (id는 위에서 찾은 change_log 번호)
insert into trips select * from jsonb_populate_record(null::trips, (select old_row from change_log where id = 123));
```
(가계부는 `expenses`, 장소는 `places`, 여행 묶음은 `journeys` 로 표 이름만 바꾸면 돼요. 여행 묶음을 먼저 되살리세요.)

## 저장이 안정적인 이유
- 저장·수정·삭제는 **화면에 먼저 반영**하고, Supabase 저장은 뒤에서 순서대로 보냅니다. 제목 옆에 `저장 중…` → `✓ 저장됨`.
- 실패하면 화면 내용은 그대로 두고 **기기에 보관한 채** 3초·10초·30초·1분·2분 간격으로 자동 재시도합니다.
  `⚠️ 저장 대기 N건`을 누르면 바로 다시 시도하고, 창을 닫았다 열어도 이어서 저장합니다.
- 모든 여행은 화면에서 만든 **ID로 덮어쓰기(upsert)** 해서, 같은 저장이 두 번 가도 한 줄만 남습니다.
  같은 사람·같은 출국일은 DB가 한 번만 받습니다(옮겨오기 중복 방지).
- 다시 열면 기기에 저장된 지난 기록을 바로 보여 주고, 최신 기록이 오면 바꿉니다.

## 문제 해결
| 화면에 뜨는 말 | 원인 | 해결 |
|---|---|---|
| Supabase 키가 맞지 않거나 권한이 없어요 | `config.js` 키가 틀림, 또는 `schema.sql`을 실행하지 않음 | 키를 다시 복사해 넣고, SQL Editor에서 `schema.sql` 실행 |
| trips 테이블을 찾을 수 없어요 | `schema.sql`을 실행하지 않음 | SQL Editor에서 `schema.sql` 실행 |
| ⚠️ 여행 묶음·가계부·장소를 쓰려면 … schema.sql을 다시 실행 | 새 테이블이 아직 없음 | SQL Editor에서 최신 `schema.sql`을 통째로 다시 실행 (기존 기록은 그대로) |
| 순서 바꾸기를 쓰려면 … schema.sql을 다시 실행 | 순서(sort_order) 칸이 아직 없음 | SQL Editor에서 최신 `schema.sql`을 통째로 다시 실행 (기존 기록은 입력 순서대로 자동 정렬) |
| 휴지통을 쓰려면 … / 준비물 체크리스트를 쓰려면 … schema.sql을 다시 실행 | 휴지통·준비물 표가 아직 없음 (그 전엔 지우면 바로 없어짐) | SQL Editor에서 최신 `schema.sql`을 통째로 다시 실행 |
| 항공편·숙소를 쓰려면 … schema.sql을 다시 실행 | 항공편·숙소 표가 아직 없음 | SQL Editor에서 최신 `schema.sql`을 통째로 다시 실행 |
| 항공편 자동 불러오기가 아직 설정 전이에요 | Edge Function `flight-lookup`이 없음 | 위 "항공편 자동 불러오기 설정" 1~5 |
| "Verify JWT"를 꺼 주세요 | 함수의 JWT 확인이 켜져 있음 | Edge Functions → flight-lookup → Details에서 끄기 |
| 항공 정보 키가 맞지 않거나 구독이 안 되어 있어요 | Secrets의 키가 틀렸거나 AeroDataBox 구독 전 | RapidAPI에서 Basic 플랜 구독·키 다시 복사 |
| 지도·장소 검색이 안 떠요 | 구글 키 제한·결제 설정 | Google Cloud에서 키의 웹사이트 제한(`https://wooriwoosin.github.io/*`), API 제한(Maps JavaScript API, Places API (New)), 결제 계정 연결 확인 |
| ⚠️ 최신 기록을 못 불러왔어요 | 인터넷 끊김, 또는 Supabase 프로젝트가 일시 정지됨 | 제목 옆 표시를 누르면 다시 시도. 계속되면 Supabase 대시보드에서 프로젝트가 **Paused**인지 확인 → Restore |
| Actions의 keep-alive가 빨간색 | 키가 바뀌었거나 프로젝트 정지 | `config.js` 확인, 대시보드에서 Restore |

GitHub는 저장소에 60일 동안 커밋이 없으면 예약된 Actions를 멈출 수 있습니다. 메일이 오면 Actions 탭에서 다시 켜 주세요.

## 예전 구글 시트 버전 (`legacy.html`, `gas/`)
Supabase로 옮기기 전에 쓰던 버전입니다. 구글 시트(Apps Script) 웹앱을 통해 저장했습니다.
- `config.js`에 Supabase 키를 넣기 전까지 `index.html`은 자동으로 `legacy.html`로 넘어갑니다.
- 옮겨오기는 `config.js`의 `oldGasUrl`(예전 웹앱 주소)로 기록을 읽어 옵니다.
- 옮겨오기와 확인이 끝나면 Apps Script 배포를 **보관처리**하고, `legacy.html`·`gas/`·`oldGasUrl`은 지워도 됩니다.
