# ✈️ 우리 가족 해외여행 기록장

가족 4명(전정순·허인선·허형준·김민정)의 해외여행을 구글 시트에 기록하고, 아래 두 가지 횟수를 **따로** 세어 줍니다.

- **출국 횟수**: 한국에서 나간 횟수 (한 번 나가서 여러 나라를 가도 1회)
- **나라 방문 횟수**: 다녀온 나라마다 1회씩 (한 번 나가서 일본·태국을 가면 2회)
- 덤으로 **가본 나라 수**(중복 제외), 총 여행일수, 연도별 출국 횟수도 보여 줍니다.

나라 이름만 입력하면 **국기(🇯🇵 이모지 + 국기 이미지)** 가 자동으로 들어갑니다.
`다낭`, `발리`, `괌`, `Japan`, `JP`처럼 도시 이름이나 영문, 국가코드로 입력해도 나라 이름으로 바뀝니다.

## 파일

| 파일 | 내용 |
|---|---|
| `Code.gs` | 시트 생성, 국기 자동 입력, 통계 계산, 웹앱 서버 코드 |
| `Countries.gs` | 나라 이름·별칭 ↔ 국가코드 목록 (약 150개국) |
| `Index.html` | 웹앱 화면 (통계 / 여행 목록 / 여행 추가) |
| `appsscript.json` | 프로젝트 설정 (서울 시간대) |

## 설치 (처음 한 번)

1. 구글 시트에서 **확장 프로그램 → Apps Script**를 엽니다. 웹앱을 이미 만든 그 프로젝트에서 하면 됩니다.
2. 파일 4개를 같은 이름으로 만들고 내용을 붙여 넣습니다.
   - `Code.gs`, `Countries.gs` → **＋ → 스크립트**
   - `Index.html` → **＋ → HTML** (이름은 `Index`)
   - `appsscript.json` → 톱니바퀴(프로젝트 설정)에서 **"appsscript.json" 매니페스트 파일 표시**를 켠 다음 내용을 바꿉니다.
3. 위쪽 함수 선택 칸에서 **`setup`** 을 고르고 **실행**을 누릅니다. 권한을 허용하면 아래 작업이 한 번에 끝납니다.
   - `여행기록` / `통계` / `나라별` / `국가목록` 탭 생성
   - 시트를 편집할 때 국기와 통계를 자동으로 다시 계산하는 트리거 설치
   - 출입국사실증명서에 있는 **김민정 출국 기록 21건** 입력 (2005.01.08 ~ 2026.09.17)
4. **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 누릅니다. 기존 웹앱 주소는 그대로 쓸 수 있습니다.
   - 실행 사용자: **나**
   - 액세스 권한: 가족이 함께 쓰려면 **Google 계정이 있는 모든 사용자** (주소를 아는 사람은 누구나 기록을 보고 고칠 수 있으니 주소는 가족끼리만 공유하세요)

## 사용법

### 웹앱에서 (휴대폰 추천)
- **통계**: 사람별 출국 횟수, 나라 방문 횟수, 가본 나라와 국기, 나라별·연도별 표를 봅니다.
- **여행 목록**: 노란색 줄은 나라가 아직 비어 있는 여행입니다. 누르면 나라를 채울 수 있습니다.
- **＋ 여행 추가**: 같이 간 사람을 **모두** 고르면 사람마다 한 줄씩 기록됩니다. 나라는 하나씩 입력하고 Enter를 누르세요.

### 시트에서 직접
- `여행기록` 탭에 여행자, 출국일, 입국일을 쓰고 `방문국가` 칸에 `일본, 태국`처럼 쉼표로 구분해 입력합니다.
  국기, 기간(`2박3일`), 나라 수, 통계는 자동으로 채워집니다.
- 빨간 칸은 국가목록에 없는 이름입니다. `국가목록` 탭 맨 아래에 나라 이름과 2자리 코드(예: `JP`)를 추가하면 국기가 붙습니다.
  자주 쓰는 도시 이름은 `별칭` 칸에 `|`로 구분해 넣으세요.
- 메뉴 **✈️ 여행기록 → 국기·통계 새로고침**으로 언제든 전체를 다시 계산할 수 있습니다.

## 다른 가족 기록 넣기

엄마, 언니, 남편도 정부24에서 **출입국에 관한 사실증명**을 떼면 출국일과 입국일을 알 수 있습니다.
웹앱이나 시트에 직접 넣거나, `Code.gs`의 `SEED_TRIPS`에 날짜를 추가한 뒤 `seedTrips`를 실행하세요.
이미 있는 출국일은 건너뛰므로 여러 번 실행해도 기록이 중복되지 않습니다.

> 증명서에는 주민등록번호와 여권번호가 들어 있습니다. 이 저장소와 시트에는 **날짜만** 옮겨 두었습니다.

## 참고
- 국기 이모지는 휴대폰과 Mac에서는 국기로 보이지만, Windows에서는 `JP` 같은 글자로 보일 수 있습니다.
  그래서 `나라별` 탭과 웹앱은 국기 **이미지**(flagcdn.com)를 사용합니다.
- 가족 이름을 바꾸려면 `Code.gs` 맨 위 `FAMILY`를 수정하세요.
